一、计算机硬件常识

CPU（中央处理器）

中央处理器是电脑工作的核心，处理器的性能就很大程度上决定了电脑的性能。

现在几乎所有 CPU 都在芯片中安装了多个核心，相当于一个个协同起来的独立的小处理器。

一些 CPU 还使用大小核设计。

从软件开发的角度，CPU负责执行程序中的指令，包括算术运算、逻辑判断、控制流程等，

多核 CPU 可以并行处理多个线程，提高程序性能。

显卡与GPU（图形处理器）

显卡是承载GPU以及其他组件的模块

  • 集成显卡，GPU 被安排在处理器的同一片芯片上，性能相对较差，能应付大多数工作，但游戏、制图等特定工作就不太行了。
  • 独立显卡，GPU 是一片独立的芯片，以显卡模块的形式安装在电脑内。性能较强，更高的功耗、更大的体积和更多的发热等。

GPU是显卡的核心组件

GPU 专门处理大量的并行计算，尤其是图形渲染和矩阵运算；

游戏、图形界面渲染依赖 GPU；

现代软件（深度学习、科学计算）利用 GPU 做大规模并行计算。

内存

误区：日常生活中所说的「手机内存不够」，其实大多指的是闪存空间不足，即「手机的硬盘」容量不够，而不是真正意义上的内存不足，对于电脑也是同理

所谓的内存用来临时存放数据的，

内存直接与处理器进行数据交流，读取与写入速度也是极快的

更多的内存意味着更多的空间来让处理器存放数据，也就意味着电脑能同时处理更多的任务，运行更加流畅

硬盘（外存）

内存是用来临时存储数据的，而硬盘则是用来长久保存数据的

读写速度较慢，但硬盘中的数据不会因为断电而轻易消失

处理器在一开始，从硬盘中取出数据放入内存，在内存中处理数据，处理完成之后，再将新的数据放回硬盘。

二、搜索引擎

常见搜索引擎

  • Google：全球最强大的搜索引擎，搜索结果准确、全面，但在国内访问需要科学上网。
  • Bing：微软推出的搜索引擎，界面简洁、结果较为国际化。
  • FireFox Search：Firefox 浏览器内置搜索服务，隐私保护较好。
  • Baidu：结果偏广告化，技术类内容质量较低。
  • 360 搜索：结果相关度较差，不适合技术类检索。

建议：在学习与开发过程中，尽量使用 Google 或Bing，能获得更准确的技术资料。

分辨广告与官网

  • 标有「广告」「推广」
  • 域名可疑（如 .cn.com、拼音混乱）
  • 认准知名网站：如 microsoft.com
  • 看清楚网址后缀 .com、.org、.edu

三、文件压缩

压缩工具

  • 7-Zip（推荐）：免费开源，支持多平台（Windows / macOS /Linux），压缩率高。
  • WinRAR：功能强大，但为商业软件，长期使用需购买授权。

常见压缩格式

格式 特点
.7z 压缩率高，推荐使用
.zip 通用性强，系统自带支持
.tar Linux 系统常见的打包格式
.tar.gz tar 打包后再压缩，常见于开源项目发布

四、磁盘管理

C盘 系统盘 仅存系统与必要软件
D盘 工作盘 存放项目、资料
E盘（如果有） 存档盘 备份、媒体资源
  • C盘：系统盘，一般存放系统文件和软件。
  • D盘/E盘：常用于存放用户数据或项目文件。
  • 路径分隔符：Windows 使用 \，Linux/macOS 使用 /。

但是\在一些情况下会被识别为转义字符，当出现路径问题时可以尝试改用/或者使用转义字符\\

软件安装建议

  • 不要安装在 桌面 或含中文、空格的路径
  • 安装到D盘或其他非系统盘 推荐：D:\DevTools\vscode
  • 将临时文件、资料、程序分类存放

七、了解编程的基本流程

环境配置 和 程序构建

（一）配置：准备写代码的环境

在真正写代码前，计算机需要知道你要用什么语言、在哪里写、怎么运行。

这就是“配置环境”。

文本编辑器 / 集成开发环境（IDE）

写代码就像写作文，只是工具不同

  • VS Code（推荐）：轻量、简洁、插件多，支持多种语言。适合初学者。
  • Visual Studio：功能强大，但体积较大，占用资源多。
  • JetBrains 系列（PyCharm、CLion、IDEA）：专业化程度高，几乎不用自己配环境。

如何安装 VS Code：
访问 https://code\.visualstudio\.com/
→ 下载并安装（默认选项即可）
→ 打开后安装插件：如 “C/C++” 插件。

编译器（Compiler）

编译器就像“翻译官”，把你写的代码翻译成计算机能理解的语言

不同语言使用的编译器不同：

语言 是否需要编译器 常见编译器
C / C++ 需要 GCC、Clang、MSVC
Python 不需要（解释执行） 内置解释器
Java 需要 JDK 自带 javac

C/C++通过编译器将源代码一次性转换成机器语言，生成可执行文件;

Python源代码在程序运行时由解释器逐行转换成机器语言;

Java源代码首先被编译成与平台无关的字节码文件（.class文件），然后这些字节码文件可以在不同平台的Java虚拟机（JVM）上运行。

环境变量（Environment Variables）

让系统知道“编译器在哪里”

环境变量是操作系统中用来设置运行环境的参数，可以影响到系统和应用程序的行为

在windows上当你修改环境变量时，相当于是在修改注册表；

当系统启动时，windows会从注册表中读取并加载这些变量；

当你打开程序时，程序也会继承系统的变量。

这些变量相当于是给一堆路径取了一个别名，

而Path变量则相对特殊，因为在进行路径查找时往往会自动在该变量中查找。

类型区分：

类型 有效范围 说明
系统环境变量 所有用户 影响整个系统
用户环境变量 当前用户 只影响个人账户
临时环境变量 当前窗口 关闭后失效

设置方法：
Windows 搜索“环境变量” / “系统属性 → 高级 → 环境变量” → 编辑Path → 添加编译器路径。

九、提问的艺术

高效提问能帮助你更快解决问题：

如何正确提问：

  1. 明确背景：说明系统、环境、语言版本。
  2. 展示代码：提供能复现问题的最小示例。
  3. 描述期望与实际：说明你期望的结果与实际发生的错误。
  4. 先查再问：尝试搜索、阅读文档后再提问。

示例：

> “为什么我的代码运行不了”
> “我在 Windows 10 + Python 3.10 环境下运行以下代码时出现
ModuleNotFoundError，请问可能的原因是什么？” 并给出报错截图和日志截图

否则我们能给出的回答只能是帮你算一卦
