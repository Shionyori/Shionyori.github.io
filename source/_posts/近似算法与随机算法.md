# 1. 旅行商问题（2-近似算法）

## 问题描述

旅行商问题（TSP）：给定一系列城市及每对城市之间的距离，求一条经过每个城市恰好一次并回到起点的最短回路。从图论角度看，也就是在带权完全图中寻找最短哈密顿环。

这是一个著名的 NP-Hard 问题，想在多项式时间内找到绝对解几乎是不可能的。因此在实际问题中，我们往往退而求其次，寻找一个在多项式时间内能运行且理论可行的近似算法。

对于满足**三角不等式**（Metric TSP）的情况：
$$d(u,w) \leq d(u,v) + d(v,w)$$
存在一个经典的 2-近似算法，其核心思想是利用最小生成树来构造一条可行的旅行路线。

## 思考过程

如果我们已经知道最优哈密顿环（记作 $OPT$），那么把其中任意一条边删除，就会得到一棵连接所有顶点的生成树（记作 $MST$），显然他们各自的边权之和满足以下关系：
$$MST \leq OPT$$
也就是说，最小生成树的权值也一定不会超过最优旅行路线的长度。

{% note info %}
虽然直接寻找最优哈密顿环很困难，但最小生成树却可以通过 Prim 或 Kruskal 算法在线性对数时间内求出，并且它天然提供了一个可靠的下界。
{% endnote %}

但是生成树并不是回路，我们应该如何利用最小生成树构造一个回路？

> 不妨将生成树的每条边都复制一份

这样每个顶点的度数都变成偶数，一定存在欧拉回路。

于是我们就得到了一条经过所有边恰好一次的回路，但是它依旧不是哈密顿环。还记得原本的图是一个无向完全图，每个点之间都可以直达。因此我们可以跳过重复顶点，最后得到一个哈密顿环。

## 算法步骤 

### 1. 求最小生成树

利用 Prim 或 Kruskal 算法求出原图的最小生成树 $T$。

设其权值为：
$$w(T)$$
由前面的分析可知：
$$w(T)≤OPT$$

### 2. 复制 MST 的所有边

将最小生成树中的每条边复制一次。

此时新图中每条边出现两次，因此：
$$w(T^′)=2w(T)$$
并且所有顶点的度数都变为偶数。

根据欧拉图定理，该图一定存在欧拉回路。

### 3. 构造欧拉回路

在复制后的图中寻找一条欧拉回路。

设得到的顶点访问序列为：
$$v_1,v_2,\ldots,v_k$$
由于树中的边被重复了一次，因此欧拉回路的总长度恰好为：
$$2w(T)$$

### 4. 跳过重复顶点

欧拉回路会多次经过同一个顶点，而 TSP 要求每个顶点只访问一次。

因此按照欧拉回路的访问顺序遍历顶点：

- 第一次出现时保留；
- 后续再次出现时直接跳过。

例如：
$$A\rightarrow B\rightarrow C\rightarrow E\rightarrow C\rightarrow B\rightarrow A\rightarrow D\rightarrow A$$
经过 Shortcut 后变成：
$$A\rightarrow B\rightarrow C\rightarrow E\rightarrow D\rightarrow A$$
得到一条合法的哈密顿环。

## 近似比分析

之所以可以像上面那样跳过重复点，是因为图满足三角不等式，例如原来路径：
$$u\rightarrow v\rightarrow w$$
如果顶点 $v$ 已经访问过，那么可以直接改成：
$$u\rightarrow w$$
并且有
$$d(u,w)\le d(u,v)+d(v,w)$$
因此不会增加路径长度，设最终得到的回路长度为 $ALG$，则有：
$$ALG\le 2w(T)$$
又因为：
$$w(T)\le OPT$$
所以：
$$ALG\le 2OPT$$
即：
$$\frac{ALG}{OPT}\le 2$$

# 2. 模拟退火算法（随机优化算法）

## 问题描述

模拟退火算法是一种随机优化算法，可以用来在一个大的搜寻空间内寻找问题的全局近似最优解。

在很多组合优化问题中，由于解空间巨大，且存在大量的**局部最优解**，传统的梯度下降法或爬山算法极易陷入这些局部陷阱而无法自拔。模拟退火算法通过引入物理学中的固体退火原理，为跳出局部最优提供了可能。

## 思考过程

模拟退火的灵感来源于固体退火原理：将固体加热至充分高，其内部粒子随之变为无序状态，内能增大；然后逐渐冷却，粒子渐趋有序，在每个温度下达到平衡态，最后在绝对零度时达到晶体状态，内能减至最小。

根据统计力学中的 Metropolis 准则：粒子在温度 $T$ 时趋于平衡态的概率分布中，能量为 $E$ 的状态概率为：
$$P(E) \propto \exp\left(-\frac{E}{k_B T}\right)$$
将其映射到算法中：

- 物理状态 $\rightarrow$ 可行解
- 内能 $E$ $\rightarrow$ 目标函数值（以求最小值为例）
- 温度 $T$ $\rightarrow$ 控制参数（随着迭代进行逐渐降低）

如果新解的质量比当前解好（$\Delta E < 0$），我们**绝对接受**它。

关键在于，如果新解比当前解差（$\Delta E > 0$），算法并不是直接拒绝，而是以一定的概率 $P$ 接受它：
$$P = \exp\left(-\frac{\Delta E}{T}\right)$$
- 在**高温**下（迭代初期），$P$ 接近 1，算法几乎以随机游走的方式在大范围内探索，极易跳出局部最优。
- 在**低温**下（迭代后期），$P$ 趋近于 0，算法逐渐退化为爬山法，专注于在当前区域进行精细搜索以趋于收敛。

{% note info %}
模拟退火算法的关键点：
1. 随机产生新解（为跳出局部最优提供可能性）
2. 随机接受变差的新解（同上）
3. 越往后温度越低，接受变差的新解的可能性也越低（避免过多的不确定性，确保收敛）
{% endnote %}

## 算法步骤

### 1. 初始化

- 设定初始温度 $T_0$（足够高），终止温度 $T_{end}$（接近 0）。
- 设定每个温度下的最大迭代次数（或称马尔可夫链长度）$L$。
- 随机生成一个初始解 $X_0$，计算其目标函数值 $E(X_0)$。令当前解 $X_{curr} = X_0$。

### 2. 产生新解

- 在当前解 $X_{curr}$ 的**邻域**内通过某种扰动（例如在 TSP 中随机交换两个城市的顺序）产生一个新解 $X_{new}$。
- 计算新解的目标函数值 $E(X_{new})$，并计算能量差：$$\Delta E = E(X_{new}) - E(X_{curr})$$

### 3. 对新解的接受判别

- 如果 $\Delta E < 0$（新解更优），则**接受新解**，令 $X_{curr} = X_{new}$。        
- 如果 $\Delta E \geq 0$（新解变差），则计算接受概率 $P = \exp(-\Delta E / T)$。
-  产生一个 $[0, 1)$ 区间的随机数 $r$：
    - 若 $r < P$，则**勉强接受新解**，令 $X_{curr} = X_{new}$；
    - 否则，**拒绝新解**，保持 $X_{curr}$ 不变。

### 4. 内循环与降温

- 在当前温度 $T$ 下重复步骤 2 和 3 共 $L$ 次。    
- 完成当前温度的搜索后，按照降温函数更新温度，通常采用线性降温：$$T = \alpha \cdot T \quad (0.8 \le \alpha < 1)$$

### 5. 终止条件

- 检查温度是否达到终止温度 $T_{end}$，或连续若干个温度周期内解未发生显著改善。    
- 若未满足，返回步骤 2；若满足，则输出搜索过程中遇到的**历史最佳解**。

# 3. 寻找最近点对问题的随机算法

## 问题描述

最近点对问题：给定二维平面上的 $n$ 个点，找出其中欧几里得距离最近的两个点。

这是一个计算几何的经典问题。暴力枚举的复杂度为 $O(n^2)$，利用分治法可以将复杂度优化到 $O(n \log n)$。然而，通过引入随机化与网格化思想，我们可以在期望 $O(n)$ 的时间内解决该问题。

## 思考过程

假设我们知道前 $i$ 个点的最近距离是 $\delta$。当第 $i+1$ 个点加入时，如果它能与之前的某个点更新最近距离，那么这个新点与目标点的距离一定小于 $\delta$。

为了快速找出哪些点可能与新点的距离小于 $\delta$，我们可以将整个二维平面划分成大小为 $\frac{\delta}{2} \times \frac{\delta}{2}$ 的网格。

{% note info %}
根据鸽巢原理，在任意一个 $\frac{\delta}{2} \times \frac{\delta}{2}$ 的网格内，最多只能容纳一个点。因为一旦有两点落入同一网格，它们的距离必然小于 $\delta \cdot \sqrt{(\frac{1}{2})^2 + (\frac{1}{2})^2} = \frac{\sqrt{2}}{2}\delta \approx 0.707\delta < \delta$，这与当前最近距离为 $\delta$ 矛盾。
{% endnote %}

因此，当一个新点 $p$ 试图更新当前全局最短距离 $\delta$ 时，我们只需要检查 $p$ 所在网格**及其周围邻近的网格**即可。

为了避免最坏情况（例如点按特定顺序排列导致频繁重构网格），我们可以先将所有输入点进行**随机打乱**。这样可以保证每次加入新点时，更新全局最小距离的概率非常低，从而实现期望 $O(n)$ 的时间复杂度。

## 算法步骤

### 1. 随机打乱

- 随机打乱输入的 $n$ 个点，排列为 $p_1, p_2, \ldots, p_n$。

### 2. 初始化

- 设前两个点 $p_1, p_2$ 的距离为当前最短距离：$$\delta = \text{dist}(p_1, p_2)$$
- 建立一个哈希表（网格容器），网格的边长设为 $r = \frac{\delta}{2}$。  
- 将点 $p_1$ 和 $p_2$ 映射到它们所在的网格坐标 $( \lfloor x/r \rfloor, \lfloor y/r \rfloor )$ 并存入哈希表中。
        
### 3. 增量式遍历与查询

- 从 $i = 3$ 到 $n$ 依次处理每个点 $p_i$：
- 计算 $p_i$ 当前所在的网格坐标 $G = ( \lfloor x_i/r \rfloor, \lfloor y_i/r \rfloor )$。
- **区域搜索**：在哈希表中查找以 $G$ 为中心的 $5 \times 5$（或 $3 \times 3$ 的大扩展圈，根据网格边长定义，若边长为 $\delta$ 则为 $3 \times 3$，若边长为 $\frac{\delta}{2}$ 则通常只需检查周边及自身共 25 个小网格）区域内的所有已有顶点。    
- 计算 $p_i$ 与这些邻近网格中点的距离：
- 如果发现了更小的距离 $\delta' < \delta$。

### 4. 网格重构

- 一旦在步骤 3 中触发了更小距离 $\delta'$，意味着网格大小不再适用。
- 令 $\delta = \delta'$，更新新的网格边长为 $r = \frac{\delta}{2}$。
- **清空原有的哈希表**，将前 $i$ 个点按照新的网格大小重新建表。
        
### 5. 结束

- 当所有点遍历完毕，最后的 $\delta$ 即为全图最近点对的距离。

## 复杂度与近似比分析

该算法是一个拉斯维加斯形式（Las Vegas）的精确随机算法，其输出结果是绝对正确的，随机性仅影响运行时间。

- 空间复杂度：存储哈希表需要 $O(n)$ 的空间。
- 时间复杂度分析：
    - 当插入第 $i$ 个点时，如果在邻近网格内查找，由于每个网格最多一个点，检查的邻居点数是个常数 $O(1)$，因此单次查询时间为 $O(1)$。
    - 如果没有更新 $\delta$，耗时 $O(1)$。
    - 如果触发了更新 $\delta$，需要将前面的 $i$ 个点重新插入哈希表，耗时 $O(i)$。
    - 根据概率几何分析，在随机打乱的前提下，第 $i$ 个点导致 $\delta$ 发生更新的概率仅为 $\frac{2}{i}$。
    - 因此，第 $i$ 步的**期望时间复杂度**为：$$E[T_i] = 1 \cdot \left(1 - \frac{2}{i}\right) + O(i) \cdot \frac{2}{i} = O(1)$$
    - 总期望时间复杂度为：    $$\sum_{i=1}^n E[T_i] = O(n)$$

{% note info %}
通过精妙地结合随机打乱与网格空间索引，算法成功将一个原本需要复杂分治的计算几何问题，在线性期望时间内精简解决。
{% endnote %}
