# 1. 什么是反射

反射是指程序在运行时（或编译期）能够检查和操作自身结构的能力。它允许程序动态地获取类型信息、访问对象的字段和方法，从而实现更灵活的编程模式。

根据执行时机的不同，可分为以下两类：
- **运行时反射（Runtime Reflection）**：如 Go、Java，程序运行期间动态查阅类型元数据，灵活但有一定性能开销
- **编译期静态反射（Compile-time Static Reflection）**：如 C++26，类型信息在编译阶段被遍历并生成代码，运行时无额外开销

# 2. Go 的运行时反射

Go 语言的反射机制主要依赖于 `reflect` 标准库包。它的设计哲学是：编译器在编译时埋入类型元数据，程序在运行时通过 `interface{}` 这个“万能容器”将类型信息提取出来。

主要涉及两个核心类型：
- `reflect.Type`：表示 Go 语言中的类型信息，通过 `reflect.TypeOf()` 函数获取
- `reflect.Value`：表示 Go 语言中的值信息，通过 `reflect.ValueOf()` 函数获取

## 2.1 获取类型和值

1. 普通变量
```go
func main() {
    x := 42
    fmt.Println(reflect.TypeOf(x))
    fmt.Println(reflect.ValueOf(x))
}
```

2. 结构体
```go
type Person struct {
    Name string
    Age  int
}

func main() {
    p := Person{
        Name: "Alice", 
        Age: 30
    }
    fmt.Println(reflect.TypeOf(p))
    fmt.Println(reflect.ValueOf(p))
}
```

## 2.2 修改值

Go 规定只有可寻址（Addressable）的值才能被修改。所以我们需要先传入指针，然后再通过 Elem() 解引用来获取可寻址的值。

```go
func main() {
    p := Person{
        Name: "Alice", 
        Age: 30
    }
    v := reflect.ValueOf(&p).Elem() // 获取可寻址的值
    v.FieldByName("Age").SetInt(31) // 修改 Age 字段
    fmt.Println(p.Age)
}
```

# 3. Java 的运行时反射

Java 的反射机制允许程序在运行时动态地获取类的信息、创建对象、调用方法和访问字段。Java 的反射主要通过 `java.lang.reflect` 包提供的类来实现，包括 `Class`、`Method`、`Field`、`Constructor` 等对象。

## 3.1 获取 Class 对象

在 Java 中，每个类在类加载器加载时都会在 JVM 的元空间中生成一个唯一的 `Class` 对象，它是反射操作的入口。

获取 `Class` 对象有三种常见方式：

1. 通过类名获取

```java
Class<?> clazz = Class.forName("com.example.MyClass");
```

2. 通过类的字面量获取

```java
Class<?> clazz = MyClass.class;
```

3. 通过对象实例获取

```java
MyClass obj = new MyClass();
Class<?> clazz = obj.getClass();
```

## 3.2 获取字段信息

通过 `Class` 对象可以获取类的字段信息（字段名、类型、修饰符等）。
- `getDeclaredFields()`：获取类中所有声明字段（包括私有字段）
- `getDeclaredField(String name)`：获取指定名称的字段（包括私有字段）
- `getFields()`：获取类中所有公共字段（包括继承的公共字段）
- `getField(String name)`：获取指定名称的公共字段（包括继承的公共字段）

```java
public class Person {
    private String name;
    public int age;
}

Field[] fields = Person.class.getDeclaredFields();
for (Field field : fields) {
    System.out.println(field.getName() + " - " + field.getType()); // 输出字段名和类型
}
```

通过 `Field` 对象，我们可以使用 `get()` 和 `set()` 方法来读取和写入字段的值。Java 的反射机制允许修改私有字段，但需要先调用 `setAccessible(true)` 来绕过访问控制检查。

```java
Person p = new Person();
Field nameField = Person.class.getDeclaredField("name");
nameField.setAccessible(true);
nameField.set(p, "Alice"); // 设置 name 字段
String name = (String) nameField.get(p); // get() 返回的是 Object 类型，需要强制转换
```

## 3.3 获取方法信息

通过 `Class` 对象可以获取类的方法信息（方法名、参数类型、返回类型等）。
- `getDeclaredMethods()`：获取类中所有声明方法（包括私有方法）
- `getDeclaredMethod(String name, Class<?>... parameterTypes)`：获取指定名称和参数类型的方法（包括私有方法）
- `getMethods()`：获取类中所有公共方法（包括继承的公共方法）
- `getMethod(String name, Class<?>... parameterTypes)`：获取指定名称和参数类型的公共方法（包括继承的公共方法）

```java
public class Person {
    public void greet() {
        System.out.println("Hello!");
    }
    
    private String getName() {
        return "Alice";
    }
}

Method[] methods = Person.class.getDeclaredMethods();
for (Method method : methods) {
    System.out.println(method.getName() + " - " + method.getReturnType());
}
```

通过 `Method` 对象，我们可以使用 `invoke()` 方法来调用方法。Java 的反射机制允许调用私有方法，但同样需要先调用 `setAccessible(true)` 来绕过访问控制检查。

```java
Method getNameMethod = Person.class.getDeclaredMethod("getName");
getNameMethod.setAccessible(true);
String name = (String) getNameMethod.invoke(p); // invoke() 返回的是 Object 类型，需要强制转换
```

# 4. C++26 的静态反射

C++26 引入了编译期静态反射，我们可以在编译期获取各种语言构造的元信息，用于生成代码或进行编译期检查。
- 在编译期完成，**运行时零开销**
- **无法处理运行时动态类型**（运行时动态生成的类、动态加载的共享库、网络传输的未知结构等），不支持运行时修改

## 4.1 反射运算符

反射运算符 `^^`，用于生成指定的语言构造的反射值（反射值的类型为 `std::meta::info`）。

我们可以通过反射值来获取语言构造的各种信息：
- `std::meta::info::kind()` 返回语言构造的种类（如 `class`、`struct`、`enum` 等）
- `std::meta::info::name()` 返回语言构造的名称
- `std::meta::info::type()` 返回语言构造的类型
- `std::nonstatic_data_members_of` / `std::static_data_members_of` 
  - 返回给定类型的非静态数据成员 / 静态数据成员的反射值列表
  - 具体的返回类型为 `std::meta::info_list`，可以通过索引访问每个成员的反射值

```cpp
struct Point { int x; int y; };

// 获取 Point 的所有非静态数据成员的反射信息
constexpr auto members = std::meta::nonstatic_data_members_of(^^Point);
// members[0] 代表 Point::x
// members[1] 代表 Point::y
```

## 4.2 拼接符（Splice）

拼接符 `[: expression :]`，用于将反射值对应的语言构造注入到代码中。

```cpp
// 利用反射生成枚举转字符串的代码（编译期完成）
template<typename E>
constexpr std::string_view enum_to_string(E value) {
    constexpr auto members = std::meta::nonstatic_data_members_of(^^E); // 获取枚举的所有成员
    for (const auto& member : members) {
        if (value == member) {
            return [: member.name :]; // 将成员名注入为字符串，注入后相当于 return "成员名";
        }
    }
    return "Unknown";
}
```
